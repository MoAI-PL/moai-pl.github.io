Design System & Developer Guidelines1. Global Design PrinciplesAesthetic Theme: Modern Glassmorphism. The UI relies heavily on depth, translucency, and frosted glass effects layered over rich, dark backgrounds.Visual Tone: Premium, immersive, and futuristic. The interface should feel weightless and fluid.Core Mechanics:Strict adherence to backdrop-filter: blur() for surface elevations.High-contrast text against dark/translucent backgrounds for maximum legibility.Subtle, semi-transparent borders to define edges without adding visual weight.2. Color SystemAll values are deterministic. Do not deviate from these exact hex or rgba values.Base PalettePrimary Background: #291650 (Deep Purple) - Used as the ultimate base layer of the application body.Primary Text: #FFFFFF (White) - Used for 90%+ of all text, headings, and icons.Accent 1 (Ivory): #FFF3CF - Used for primary actions, active states, highlights, and warning semantics.Accent 2 (Pale Red): #E55858 - Used for secondary actions, notification dots, destructive actions, and error semantics.Glass Surface Colors (Translucent)Surfaces use white with varying opacities to create the frosted glass effect against the #291650 background.Surface Level 1 (Base Card): rgba(255, 255, 255, 0.05)Surface Level 2 (Elevated Card/Modal): rgba(255, 255, 255, 0.08)Surface Hover State: rgba(255, 255, 255, 0.12)Glass Border (All Surfaces): rgba(255, 255, 255, 0.15)Text ColorsText Primary: #FFFFFF (100% opacity)Text Secondary: rgba(255, 255, 255, 0.70) (Muted white for subtitles, placeholders, and metadata)Text Inverse/Dark: #291650 (Used ONLY when text is placed directly inside an Ivory #FFF3CF solid button or badge).Semantic ColorsSuccess: #4ADE80 (Standard Green - fallback for success states if Ivory/Pale Red do not fit logically).Warning: #FFF3CF (Ivory)Error / Destructive: #E55858 (Pale Red)Info: rgba(255, 255, 255, 0.9)3.
